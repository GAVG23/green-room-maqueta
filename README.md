# Green Room · maqueta de la web

Propuesta **Túnel** para la web de Green Room Surf Shop, en revisión.

Es una maqueta de diseño en un solo archivo, no la tienda. Nada de lo que se
escribe en ella se guarda ni se manda a ningún lado, y las cifras del estado del
mar son de muestra.

Lleva `noindex`, así que no sale en buscadores.
